# J280 倒立摆工程说明

## 1. 工程概况

J280 旋转倒立摆工程基于 Gowin GW2A-55（GW2A-LV55PG484C8/I7），50 MHz 主时钟，控制周期 1 kHz，串口遥测 100 Hz。工程由以下部分组成：

- 角度内环 + 编码器位置外环 + 自动起摆状态机；
- TB6612 电机驱动、编码器正交解码、ADC 角度采样；
- 128×160 ST7735 SPI 屏幕：椭圆/旋转臂/物理摆杆伪 3D 显示 + 参数表；
- 上位机 GUI：串口参数下发、遥测曲线、模式切换、参数保存；
- 上位机/本地双模式：原板 SW1 切换。

本目录是**唯一当前工程**，不保留历史版本、实验记录和旧配置。

## 3. 当前配置

**唯一配置：`gui/data/config0.json`。**

- FPGA 上电默认参数（`cfg_regs` 复位值）与 `config0.json` 的 `params` 完全一致；
- GUI 启动时自动载入 `config0.json`；
- 工程内不再提供其他参数组或历史配置文件；
- GUI 中修改参数只影响本次运行；需要保留实验参数时，自行备份 `config0.json`。工程不内置其他预设或配置。

配置参数表和串口协议见 [参数与通信协议.md](参数与通信协议.md)。

## 4. 工作模式

| MODE | 名称 | 行为 |
|---:|---|---|
| 0 | 停机 | 电机输出 0，积分清零；上电默认 |
| 1 | 手动稳定 | 摆杆进入直立窗口后接管，角度环 + 位置外环 |
| 2 | 自动起摆 | 摆幅/相位驱动起摆，捕获后转入平衡 |
| 3 | 绝对位置 | 与 MODE1 相同的接管条件；位置外环以 32 位累计编码器计数拉向 `TURNS_POSTGT`；原 `POSTGT` 无效 |

MODE3 进入方式：GUI 的“绝对定位 MODE 3”按钮，或屏幕本地模式右栏选 MODE=3 后应用。其它模式行为不变。

## 5. 屏幕界面与按键

屏幕参数表：

```
左栏：SPD（PKD）
      POS（POSTGT，±5，519↔-520 回绕）
      P  （TURNS_POSTGT，signed16）
右栏：MODE（0..3）
```

- 原板 SW1：短按切换上位机/本地模式；SW2 请求 MODE2；SW3 请求 MODE0；
- 扩展板 SW4_S/SW5_S：左栏选行；
- SW1 编码器：修改选中值；SW1_S：应用（SPD→ID 27、POS→ID 29、P→ID 48）；
- SW2 编码器：MODE 0→1→2→3→0；SW2_S：应用（ID 5）；
- 上位机模式屏幕只读；本地模式编辑值黄色/未应用橙色；
- 本地模式下仍允许上位机 `MODE=0` 急停帧通过。

屏幕上半区仍是椭圆、旋转臂（编码器相位）和物理摆杆（`ang001`）伪 3D 显示；界面刷新 20 Hz，不影响 1 kHz 控制环。

颜色约定：**黄色粗线** = 真实编码器旋转臂；**绿色细线** = 当前 POS 参数指示的预览臂（不是真实臂位置）；**青色** = 物理摆杆；**白色端点** = 实际摆杆端点。

## 6. 安全注意

- H1 的 1/3/5 脚是 5 V，绝不能接 H5 信号或 FPGA 输入；H1 10/12/14/16 为 3.3 V；
- 电机、编码器、屏幕共地；屏幕逻辑 3.3 V，不要用 5 V 信号直驱；
- 首次上电或改参数后先把 `LIM` 设小，准备好实体急停；
- `FALL`、MODE0、按键/串口急停和机械限位是最后保护，不由 GUI 代替；
- 参数默认值来自 `config0.json`，但机械零点 `ZERO/TRIM/方向` 必须按本机重新核对。
