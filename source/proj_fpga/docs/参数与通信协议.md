# J280 参数与通信协议

本文给上位机 GUI、串口工具和 FPGA 固件之间约定当前最终协议的**唯一说明**。历史 ID、旧遥测格式、旧配置组均已废弃。

## 1. 串口与参数帧

- UART：**115200 bps，8N1**，无硬件流控；FPGA 50 MHz 时钟。
- 参数帧固定 4 字节：

```text
AA | IDX | VALUE_HI | VALUE_LO
```

- `AA`：帧头；
- `IDX`：参数编号（见下表）；
- `VALUE_HI/VALUE_LO`：16 位二补码，大端；负数直接按 `int16 & 0xFFFF` 发送；
- 无校验、无应答；连续发送时每帧独立，FPGA 不会回 ACK。参数是否生效由遥测中的版本计数/界面上报确认。
- 字节间超时约 2 ms 会复位接收半帧；本地模式会屏蔽上位机参数帧，但允许 `MODE=0`（急停）通过。

说明：

- `MODE` 只接受 0/1/2/3；其它值被忽略。
- `POSTGT` 是单圈目标（-520..519，最短环绕）；`TURNS_POSTGT` 只在 MODE3 使用，是完整的 32 位累计计数目标，`POSTGT` 在 MODE3 下无效。
- MODE3 的 `TURNS_POSTGT` 使用完整 32 位计数差（位置外环按 17 位饱和），不再按 16 位周期回绕。
- `DZW` 协议值 64 对应内部移位 6；GUI 里显示 64。
- 所有参数都可以在 GUI 中单项发送/全量下发；屏幕本地模式只编辑 SPD/POS/P/MODE 四项。

## 3. 遥测帧

FPGA 每 100 ms 发送一行 ASCII（100 Hz），当前长度 **103 字节含 CRLF**：

```text
ANG=+012.34 RAW=0508 POS=-00520 SPD=-0080 DUT=+0127 REF=+0000 M1B5 SW=0 Vy6 ABS=0000ABCD SRC=0 HLD=1
```

字段含义：

| 字段 | 说明 |
|---|---|
| `ANG` | 摆杆角度（0.01°，相对竖直；带符号小数） |
| `RAW` | ADC 原始码值（0..1023） |
| `POS` | 单圈编码器位置（-520..519） |
| `SPD` | 编码器速度（count/s） |
| `DUT` | 当前 PWM 输出（duty） |
| `REF` | 角度参考/位置外环修正后的目标（0.01°） |
| `M<mode>B<status>` | 模式 0..3；`status` 为十六进制状态位 |
| `SW=0/1` | 自动起摆是否激活 |
| `V<version><count>` | 固件版本 token，例如 `Vy6`：`y` 为 BUILD60 版本字母，末位为配置接收计数 |
| `ABS=xxxxxxxx` | 32 位累计编码器计数的十六进制（二补码；GUI 按 signed32 解释） |
| `SRC=0/1` | 0=上位机模式，1=本地模式 |
| `HLD=0/1` | 位置保持是否激活 |

上位机解析建议：

```text
ANG=(?P<ang>[+-]\d+\.\d+) RAW=(?P<raw>\d+)
POS=(?P<pos>[+-]\d+) SPD=(?P<spd>[+-]\d+) DUT=(?P<dut>[+-]\d+)
REF=(?P<ref>[+-]\d+) M(?P<mode>\d)B(?P<status>[0-9A-F])
(?:\s+SW=(?P<sw>[01]))?\s+V(?P<ver>\S+)
(?:\s+ABS=(?P<abs>[0-9A-Fa-f]{8}))?
(?:\s+SRC=(?P<src>[01]))?
(?:\s+HLD=(?P<hld>[01]))?
```

旧固件的遥测可能没有 `ABS/SRC/HLD`，新 GUI 已按可选字段兼容。

## 4. GUI 约定

### 4.1 唯一配置

- 工程只保留 `gui/data/config0.json`；
- GUI 启动时自动读取 `config0.json` 的 `params`，并逐项做协议范围校验；
- FPGA 上电默认值就是同一组 `params`；
- GUI 不内置其它参数组，也不提供额外的配置选择；需要保留实验参数时自行备份 `config0.json`，工程不附带其它配置文件。

### 4.2 GUI 操作

- 连接串口后，参数区可单项“发送”或“全量下发”；
- MODE0/1/2/3 按钮分别发送 ID5 的 0/1/2/3；MODE3 在 GUI 中显示为“绝对定位 MODE 3”；
- `TURNS_POSTGT` 只在 MODE3 下作为绝对位置目标；
- 全量下发会发送表中全部参数；切换模式前请确认 `LIM`、`FALL`、`TRIM` 等安全参数；
- GUI 曲线使用上述遥测字段；`ABS` 按 signed32 显示，`SRC/HLD` 可作为状态显示。

### 4.3 本地模式/屏幕

- 原板 SW1 短按切换上位机/本地模式；
- 本地模式屏幕可编辑 SPD/POS/P/MODE，参数帧由屏幕生成后送 cfg_regs；
- 本地模式屏蔽上位机参数帧（避免争用），但保留 `MODE=0` 急停帧；
- 屏幕刷新 20 Hz；控制环仍 1 kHz。
